# AI Transparency in Public Benefits: State Law Map

Static site (no build step). Maps state and federal laws and bills on how **government agencies** use AI / automated decision systems, focused on public benefits (Medicaid, SNAP, unemployment, eligibility), against a framework: public inventory, notice and explanation, impact assessment and monitoring, human review and appeal, vendor duties, oversight and enforcement.

Every framework tag has a word-for-word quote from the bill or memo text, with its section number and a link to the full text, so tags can be cross-checked with Ctrl+F.

- `index.html`, `styles.css`, `app.js`: the site
- `data/policies.js`: every entry (generated by `tools/build_policies.py`)
- `data/quotes.js`: the verified quotes (generated by `tools/merge_quotes.py`)
- `vendor/`: d3-array, d3-geo, topojson-client and US state shapes
- `archive/`: an earlier version that mapped general state AI laws. Not used by the site.
- `tools/`: scripts that rebuild the data. `legiscan_api.py` and `fetch_texts.py` need a LegiScan API key supplied as an environment variable (`LEGISCAN_API_KEY`) or a `.env` file kept OUTSIDE this folder (point `LEGISCAN_ENV` at it). Never commit a key.

Bill data from LegiScan (CC BY 4.0); federal memos from whitehouse.gov.
